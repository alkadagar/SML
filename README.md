# SML Workspace

This is a minimal starter workspace for building a static web project in the current folder.

## Included files

- `index.html` — the landing page
- `styles.css` — page styling
- `script.js` — small interactive script
- `.vscode/tasks.json` — VS Code task to run a local web server

## Run locally

Open the project in VS Code and run the task:

- Terminal > Run Task > `Serve website`

Or, from the terminal in this folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000
